# Contributing

This repository accompanies a published paper and is maintained primarily for
reproducibility. Issues and pull requests that improve clarity, fix bugs, or
extend the experiments are welcome.

- Please keep changes reproducible: random seeds are fixed and results are
  expected to match the paper.
- Run the smoke tests before opening a PR: `pytest -q tests/`.
- For substantive questions about the method, please cite and refer to the
  paper (see `CITATION.cff`).
